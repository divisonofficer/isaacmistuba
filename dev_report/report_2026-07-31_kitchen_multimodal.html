렌더 규약 — unified band carrier. 3-별도패스(RGB passive · pseudo-NIR-swap flash · polar)를 폐기하고, 모든 재질을 blendbsdf(weight, __vis, __nir)로 감싼 band carrier 씬(spectral_band.build_band_scene)을 cuda_ad_rgb_polarized로 1회 로드 → 재질 weight를 0(visible)/1(NIR)로 flip(재로드 없음) → Stokes로 RGB·NIR·DoP·AoLP를 한 번에 뽑는다. __nir은 __vis의 deep copy라 BSDF 플러그인·물리 파라미터(alpha·normal·IOR·η/k)가 동일하고 diffuse albedo만 hybrid NIR 반사율(synthesize_nir_texture)로 바뀐다 — 금속/유리는 diffuse albedo가 없어 Fresnel 그대로(밴드 불변). 양 밴드가 동일 passive 조명 + max_depth 8이라 유리가 투과하고 금속 반사가 일관 — 옛 flash·depth-3 아티팩트(금속거울·유리검정)가 사라진다.
property map(albedo/normal/roughness/metallic)은 integrator를 안 거치고 primary-ray scene.ray_intersect로 직접 추출한다(아래).

Viewpoint 0 — vp_000005

position (world XZ) = [3.92, 2.92]

RGB — visible band
band carrier의 visible 밴드(weight 0) Stokes S0. 동일 씬·동일 passive 조명.
NIR — 854 band
같은 band carrier의 NIR 밴드(weight 1) S0. __vis와 BSDF·물리파라미터 동일, diffuse albedo만 hybrid NIR 반사율로 교체. 컬러 박스가 NIR에서 회색으로(밴드차이), 유리는 양밴드 투명(Fresnel·max_depth 8), 금속 일관.
DoP (red–black)
NIR 밴드 Stokes 편광도. specular/유리에서 편광(빨강), diffuse는 검정.
AoLP (hue=angle)
편광각을 색상(hue)으로: 각도별 다른 색. 채도=DoLP라 무편광은 흰색, 편광 강한 곳(창유리·모서리)만 선명.
Albedo (ray_intersect)
primary-ray 직접 추출한 visible base color(조명 무관). AOV 아님 — 아래 property map 참고.
Normal (world sh_normal)
primary-ray shading normal(월드): normal map 있으면 perturbed, 없으면 폴리곤 기하 법선. 벽 방향별 색·바닥=위.
Roughness map
canonical roughness(유리=0·매트=high). ray_intersect로 UV 직접 lookup — AOV backend stripe 버그 우회.
Metallic map
canonical metallic(전도체=1, 나머지 0). .blend authoring 권위 — 누출 glTF factor/texture 배제.

메모

  • RGB/NIR = 같은 band carrier, weight flip. tools/render_kitchen_unified.py가 band 씬을 1회 로드하고 재질 weight를 0/1로 바꿔 두 밴드를 뽑는다. RGB와 NIR은 동일 BSDF·물리 파라미터이고 diffuse albedo만 밴드별로 다르다. 밴드 차이는 diffuse 재질에서 드러난다 — 컬러 박스가 NIR에서 회색(NIR 반사율)으로. 금속·유리는 visible↔NIR 광학이 비슷해(Al ~92%, IOR~1.5) 두 밴드가 유사한 게 정상.
  • 유리/금속 아티팩트 해소. 옛 pseudo-NIR는 point flash를 썼는데, 그때 금속이 거울(flash 반사)· 유리가 검정(max_depth 3이 다중 굴절면 투과를 잘라 불투명)으로 렌더됐다. band carrier는 양 밴드가 동일 passive 조명 + max_depth 8이라 유리가 투과하고 금속 반사가 일관 — 둘 다 렌더 설정 아티팩트였음이 확인됐다.
  • property map = primary-ray ray_intersect(핵심). depth/normal/roughness/metallic/albedo는 광수송이 아니므로 integrator를 안 거치고 scene.ray_intersect로 직접 추출한다. 이 빌드의 aov integrator·film 누적 backend가 spp에 비례해 AOV에 규칙적 세로 stripe를 주입하는 버그가 있어(평면 하나 depth가 spp=1 매끈→spp=4096 빗살, RGB path는 클린) 옛 mapviz(albedo AOV) roughness가 노이지했다. ray_intersect는 integrator·film·spp를 통째로 우회해 clean.
  • meaningful roughness + provenance 계약. roughness는 canonical semantics에서 실제값을 유도한다: smooth dielectric(창유리)→0.0, Lambertian→1.0, alpha 스칼라→그 값, 미상만 magenta(가짜 0.5 안 씀). metallic은 .blend authoring 권위 — Blender glTF export가 절차적 재질에 누출한 metallicFactor=1.0· fabricated metallic 텍스처를 배제(전도체만 1). 각 파라미터의 baked/derived/prior/undefined + valid를 material_canonical.json(apps/material_pipeline.py)에 기록.
  • AoLP 컬러맵. 편광각을 hue로 인코딩(0°≡180° cyclic), 채도=DoLP(무편광→흰색). S0≈0 픽셀의 DoLP=0/0(NaN)은 0으로 처리. DoP는 창유리·모서리 등 Fresnel specular에서 집중.
  • 순수 analytic 재질 계약. 씬을 pplastic·roughconductor·dielectric 3종으로 정규화 (measured pBRDF는 편광 정확도용 옵션 anchor일 뿐 기본 아님 → build_band_scene force_analytic이 measured→pplastic, smooth conductor→roughconductor로 접음). 렌더 계약(material_contract §4): roughconductor source-faithful(base_color를 F0로 1회만; Al×base_color 이중곱 제거) + microfacet alpha=r²(Blender Principled). 계약은 band carrier(렌더)에만, render_scene.xml은 원본 r/base_color GT로 유지.
  • 금속 albedo. rough conductor는 diffuse+specular 혼합이므로 albedo=0(거울)이 아니라 그 base_color(specular_reflectance)가 금속색. property albedo가 이를 반영(어두운 gunmetal 컵은 회색으로). 단 RGB 실렌더에선 금속이 환경을 반사하므로 어두운 환경에선 어둡게(NIR flash로 highlight 관측).
  • NIR = band-gated active flash. band carrier에 rig NIR point 광원을 얹고 밴드별로 radiance를 flip: visible=0(passive), NIR=on. 한 씬·한 weight flip으로 RGB엔 안 보이고 NIR엔 보이는 액티브 조명 (주변광의 ~50×, 금속 highlight 관측 목적).
  • --no-polar 고속 모드. 편광이 불필요하면 path integrator(cuda_ad_rgb)로 RGB/NIR만 (DoP/AoLP 생략) → 실측 ~5× 빠름(1024spp vp_000012: Stokes 76/65s vs path 12/15s). max_depth 8 + 복잡 재질이라 Mueller 행렬 연산이 지배적. 이 리포트는 DoP/AoLP 위해 polar로 렌더.
  • 남은 작업: band 렌더 노출/조명 튜닝, stage2 spectral η/k 정밀화, property map float EXR + valid mask, render_daemon 본체에 계약 채택.
