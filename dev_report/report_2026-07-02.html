NIR spectral albedo 준비 & IOR 할당 — 상황 분석 · 자료조사 · 계획

2026-07-02 tri-modal (RGB · NIR · polar) spectral albedo measured-anchored lookup 분석/계획 (구현 전)

요약

RGB만이면 int_ior=1.5 몰빵이 방어되지만, NIR + 편광이 붙으면 판이 바뀐다. 그리고 방향이 반직관적이다 — 진짜 깨지는 건 유전체 IOR이 아니라 spectral albedo 쪽이고, IOR이 문제되는 지점은 유전체가 아니라 금속으로 넘어간다.

결론 미리: (1) 유전체 n은 visible→NIR가 거의 평평(Δn≈−0.005~−0.01) → 고정 1.5는 NIR 편광 기하까지 그대로 전이. 파장별 IOR 테이블 불필요. (2) base_color가 RGB 3-point라 NIR diffuse 반사율은 복원 불가능한 4번째 독립 채널(식생 red-edge / dye·잉크 NIR 투명 / 피부 / 직물). 현재 analytic NIR 렌더는 RGB를 luminance로 collapse하는 proxy라 이 독립성을 통째로 지운다. (3) 금속은 conductor_preset이 NIR complex n,k·편광 반사를 좌우 → dead field에서 load-bearing으로 뒤집힌다. 제안: 클래스별 NIR 반사율을 discrete 4번째 밴드로 주입하되 — hpBRDF measured(854, raw로 940) 앵커(Tier A) + 외부 스펙트럴 라이브러리(Tier B) — 그리고 편광과 커플링시킨다.

왜 spectral albedo가 핵심인가 (파장별 물리)

재질NIR 거동RGB→NIR 파생 시 오류
식생 (greenery/monocot/cactus/coral)엽록소 red-edge, NIR 40–60% vs red ~5–10%밝아야 하는데 어둡게 나옴
염색 직물 (sofa/fabric, 어두운 base)dye transparency — 검은 셔츠가 NIR에서 밝아짐어두운 색의 NIR 상승을 못 잡음
인쇄물 (text/art/paint, 로고·포스터)process 잉크 NIR 투명, 카본블랙만 남음NIR에서 글자·로고가 사라져야 하는데 그대로 유지 (문서 forensics 효과)
피부 (nose/tongue/ear)800–1100nm 고반사(멜라닌 무관) + NIR SSS 급증, 970nm 물흡수 딥어둡고 표면적으로 나옴

편광 커플링이 벤치마크상 핵심: diffuse는 대체로 unpolarized, specular가 편광을 싣는다. 유전체 n이 평평하니 specular(≈4%)는 NIR에서도 고정인데, diffuse albedo가 NIR에서 뛰면 DoLP≈specular/(specular+diffuse)가 떨어진다. 식생·어두운 직물은 NIR에서 DoLP 급감. base_color를 파장 불변으로 두면 RGB DoLP는 맞는데 NIR DoLP가 틀리는 형태라 눈으로도 안 걸러진다. subsurface(피부/대리석/잎/왁스)도 NIR 투과↑ → depolarization↑로 같은 방향.

2. 자료조사 (외부 데이터 · 방법론)

스펙트럴 라이브러리 — measured DB가 못 덮는 클래스용

  • ECOSTRESS 3400+ 스펙트라, 0.35–15.4µm(850·940 포함), 식생/토양/암석/인공물 — speclib.jpl.nasa.gov (RSE 2019)
  • LOPEX'93 / ANGERS 잎 반사·투과 400–2500nm, red-edge + NIR plateau(700–1100nm) — ecosis.org LOPEX93
  • PROSPECT 잎 반사율 생성 모델(생화학 파라미터 → 400–2500nm) — 잎 클래스 절차적 대안
  • 피부 NIR: 800–1100nm 고반사(멜라닌 무관), 970nm 물흡수 딥(940밴드 영향) — NIST skin reflectance, PMC8078188

measured → analytic 피팅 방법론 ("룩업"의 근거)

Fresnel Microfacet BRDF 계열이 (IOR, albedo, roughness, eta·k)를 measured pBRDF에 least-squares로 추정하는 표준 접근을 제공한다 — arXiv 2212.04483, multiple-lobe analytical BRDF fitting. 즉 "measured 샘플에 analytic 파라미터를 맞춘다"는 방향은 검증된 방법이다.

주의 (forward 합성 무결성): Gated2Gated류/cross-spectral RGB→NIR translation은 ground-truth 생성기로 쓰면 안 된다. NIR을 f(RGB)로 합성하면 라벨에 "NIR=f(RGB)" 가정을 구워 넣어, tri-modal이 착취해야 할 out-of-band 시그니처를 예측기가 정확히 지운다(순환 벤치마크). RGB→NIR은 baseline 방법이나 실측 데이터 augmentation에만. GT 생성은 클래스별 실측 스펙트럼 할당으로.

3. 제안 — 2-tier 클래스별 스펙트럴 albedo 룩업

"measured 샘플과 비교해 lookup으로 analytic+PBR 매칭"을 2계층으로 구체화. 두 계층 모두 단일 산출물로 수렴: class → {ρ446, ρ542, ρ614, ρ854, ρ940, roughness, (eta,k)}.

Tier A — measured-anchored (hpBRDF가 덮는 클래스)

  1. 오프라인 캘리브레이션이 14종 .pbrdf tensor를 밴드별 로드(Mitsuba tensor_file, wvls 배열 포함 → 렌더 없이 텐서에서 반사율 직접 추출).
  2. 밴드별 추출: 유효 diffuse albedo ρ(λ)(near-normal Mueller m00), roughness(마이크로패싯 로브 폭), 금속은 DoLP(θ) 서명 → eta,k.
  3. 앵커→클래스 매핑: aluminum→metal_aluminum, fake_gold→metal_gold, suj2→metal_steel, white_smooth_plastic→plastic/ceramic, *_rough_plastic→plastic, *_silicone→rubber, black_glass→glass.
  4. 전이 가능한 시그니처 = NIR/visible 비율(ρ854/ρ614 등)을 클래스에 저장.

hpBRDF 14종: aluminum · fake_gold · suj2 · black_glass · white/yellow/red/plum/silver/black_rough_plastic · white_smooth_plastic · white_billiard · gray/green_silicone. (커버: 금속·플라스틱·실리콘·유리·빌리어드. 미커버: 식생·피부·직물·잉크·나무·토양 → Tier B.)

Tier B — library-anchored (hpBRDF가 못 덮는 클래스)

식생·피부·직물·인쇄물·나무·토양 → ECOSTRESS/LOPEX/ANGERS/skin 곡선을 4(+1)밴드에서 샘플해 같은 ρ(λ)·NIR/vis 비율로 저장. RGB에서 유도하지 않음.

렌더 적용 (per-instance, 색 다양성 보존)

  • Infinigen 인스턴스의 가시광 RGB(base_color/atlas)는 그대로 유지.
  • NIR 밴드 diffuse_reflectance = class_NIR/vis_ratio × (instance visible brightness) → 인스턴스별 색 변화 보존 + NIR 물리는 클래스에서 주입.
  • NIR 렌더 패스가 이 값을 diffuse_reflectance로 emit(현재의 luminance-proxy 대체). measured가 854에서 채널-스왑하는 것과 동일 메커니즘 → Mitsuba 830nm 한계 회피.

편광 커플링은 자동: specular 고정 + NIR diffuse 상승 → DoLP가 식생·어두운 직물에서 자동 하락. 올바른 NIR albedo만으로 cross-modal 서명이 물리적으로 성립. (skin/marble/leaf는 NIR SSS/depolarization 추가로 diffuse DoLP 추가 하락 — 선택.)

5. 신규 아티팩트

  • tools/calibrate_nir_albedo.py — Tier A 오프라인 피팅(측정 텐서 → 클래스 테이블).
  • data/spectral/class_nir_reflectance.json — 클래스별 5밴드 반사율 + BSDF 파라미터.
  • modules/mitsuba_converter/src/mitsuba_converter/spectral_albedo.py — 렌더타임 룩업(optical_constants 미러 패턴).
  • 렌더 와이어링(NIR 패스) + 검증 스크립트.
한 줄 정리: IOR 튜닝은 사실상 끝났고(램프갓만), 진짜 작업은 discrete NIR 밴드 albedo를 클래스별로 — measured 앵커(Tier A) + 외부 라이브러리(Tier B)에서 — 할당하고 편광과 커플링시키는 것. "measured 룩업 매칭"은 Tier A 캘리브레이션으로 실현되고, measured가 못 덮는 판별력 있는 클래스는 Tier B가 채운다.
