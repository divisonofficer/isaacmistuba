Infinigen 시리즈 보고서

두 논문을 따로 요약하지 않고, 하나의 연구 프로그램으로 읽도록 구성한다.

Infinigen은 "정적 에셋 수집"을 "생성 규칙 설계"로 바꾸었고, Infinigen Indoors는 그 철학을 자연 세계에서 인간이 설계한 실내 세계로 확장했다.

Infinigen 2023: arxiv.org/abs/2306.09310 · Infinigen Indoors 2024: arxiv.org/abs/2406.11824

현재 보고서 진단: 내용은 좋은데, 두 논문이 살짝 따로 논다

좋은 점
  • Infinigen 2023과 Infinigen Indoors 2024의 핵심 질문이 잘 분리되어 있다.
  • "에셋 라이브러리가 아니라 생성 규칙"이라는 중심 문장이 선명하다.
  • 마지막에 "Geometric Diversity ≠ Optical Diversity"로 우리 연구 방향까지 연결한 점이 좋다.
아쉬운 점
  • 두 논문이 모두 "100% 절차적 생성", "정답 기하", "데이터 생성"을 설명하므로 반복감이 생긴다.
  • Node Transpiler, Material Generator, Ground Truth는 시리즈 공통 기반으로 한 번만 설명하는 편이 읽기 쉽다.
  • OpticalNav 연결이 2023 파트와 2024 파트에 각각 들어가면서 결론의 힘이 분산된다.
가장 좋은 수정 방향은 "논문 1 요약 → 논문 2 요약"이 아니라, "시리즈 공통 철학 → 2023의 기초 시스템 → 2024의 실내 확장 → 우리 연구로의 피벗"이다.

보고서 중심 문장을 하나로 묶기

Infinigen 2023

자연 세계의 생성 규칙화.
나무, 지형, 식물, 동물, 자연 현상을 외부 에셋 없이 생성한다.

Infinigen Indoors 2024

인공 세계의 생성 문법화.
가구·문·계단·방 구조와 실내 배치 상식을 생성 규칙과 제약으로 표현한다.

OpticalNav 관점

기하 세계에서 광학 관측으로.
무엇이 있는가를 넘어, 로봇 센서에는 어떻게 보이는가를 다룬다.

에셋 수집의 한계 ↓ 생성 규칙으로 자연 세계를 만든다 — Infinigen 2023 ↓ 생성 규칙 + 배치 제약으로 실내 세계를 만든다 — Infinigen Indoors 2024 ↓ 실내 세계에 광학 재질·센서 관측·로봇 상태를 붙인다 — OpticalNav 방향

중복 정리 원칙

현재 반복되는 내용수정 위치정리 방식
합성 데이터 병목, 정적 에셋 라이브러리 한계 서론 한 번 두 논문의 공통 문제의식으로 합친다.
100% 절차적 생성, 외부 에셋 없음 시리즈 공통 철학 2023에서 처음 제시, 2024에서 계승·확장으로 설명한다.
Node Transpiler 공통 제작 도구 2023의 기반 도구로 설명하고, 2024에서는 "계승된 제작 방식" 정도로만 언급한다.
Material Generator / Real Geometry 공통 데이터 품질 원칙 가짜 기하를 피하는 이유는 한 번 설명하고, 실내 재질은 coverage 확장으로만 추가한다.
Ground Truth extraction 시리즈 공통 효용 depth, normal, segmentation, optical flow는 "왜 비전 학습 데이터가 되는가"에서 한 번만 설명한다.
OpticalNav 연결 마지막 단일 결론 2023/2024 각각에 붙이지 말고, 마지막에 "기하 다양성에서 광학 다양성으로" 한 번에 묶는다.

Infinigen 2023은 "기초 운영체제"처럼 설명한다

핵심 성취

외부 에셋 없이 자연 세계의 형상·재질·장면을 절차적으로 만든다. 182개 생성기, 1,070개 자유도.

핵심 도구

Node Transpiler가 아티스트의 노드 그래프를 Python 생성 코드로 바꾼다. 그래프 구조까지 무작위화 가능.

핵심 품질

범프 맵 같은 가짜 디테일을 피하고 실제 메쉬 기반 정답 기하를 유지한다. depth / normal / segmentation 신뢰 가능.

여기서 너무 많은 자연물 세부 구현을 길게 풀면 2024 파트로 넘어가기 전에 독자가 지친다. 나무·잎·지형은 대표 예시만 남기고, 핵심은 "생성 규칙의 일반성"으로 압축하는 편이 좋다.

자연물 생성 5계층 (요약)

계층생성 내용핵심 방식
형상 생성기나무·식물·동물·바위 큰 구조성장 법칙, 공간 점유 알고리즘
재질 생성기색·반사율·거칠기·투과·표면 패턴절차적 셰이더, 파라미터 무작위화
국소 기하 생성기표면 주름·바위 균열·나무껍질스칼라 필드 → 정점 변위 (실제 메쉬)
표면 스캐터 생성기풀·이끼·돌·낙엽독립 3D 물체 인스턴싱
장면 구성 생성기숲·사막·해안·수중 환경 전체지형·식생·기상 조건 종합 배분

왜 가짜 기하를 피하는가 — 컴퓨터 비전 학습 데이터의 핵심

범프 맵 / Phong 보간
표면 법선을 조작해 울퉁불퉁해 보이게 한다. 실제 메쉬는 평평하다.
→ depth/normal 정답이 실제 기하와 어긋난다.
→ CV 학습 데이터로 신뢰하기 어렵다.
Infinigen 실제 메쉬
보이는 것 = 실제 메쉬 구조.
→ depth, normal, occlusion boundary, segmentation 정답이 정확하다.
→ 별도 annotation 없이 정답 자동 추출 가능.

Infinigen Indoors 2024는 "실내 문법 확장"으로 설명한다

오브젝트 확장

79개 절차적 오브젝트 생성기. 가구·가전·문·창문·계단·소품을 외부 에셋 없이 생성한다.

배치 확장 (신규 기여 핵심)

실내 상식을 Python 기반 제약 언어로 표현하고, Simulated Annealing 솔버가 배치를 찾는다.

로봇 연결

Omniverse, Unreal Engine 5, Isaac Sim으로 export. URDF 자동 생성. RTX 4090 대화형 프레임레이트.

2024 파트의 주인공은 Node Transpiler가 아니라 "제약 기반 실내 배치"다. 자연물 생성 규칙에서 실내 공간 설계 문법으로 넘어간 것이 시리즈의 진짜 장면 전환이다.

인공물 vs 자연물 — 생성 방식의 차이

자연물 생성 (Infinigen 2023)
핵심 법칙: 성장과 물리적 형성

실험 섹션은 "무엇을 증명했는가"로 압축하기

논문실험핵심 결론
Infinigen 2023 30K stereo pair → RAFT-Stereo 학습 → Middlebury 비교 절차적 자연 데이터가 기존 합성 데이터의 자연 도메인 부족을 보완. Jadeplant 같은 복잡 자연물 장면 강점.
Infinigen Indoors 2024 Shadow removal (2K쌍), Occlusion boundary estimation (1464장) 실내 특화 합성 데이터가 실내 비전 일반화 향상. Infinigen-Nature, Hypersim 대비 ODS/OIS/mAP 우위.
시리즈 전체 에셋 수집이 아니라 생성 규칙을 튜닝하는 데이터 생성 방식 데이터셋을 "만들어진 이미지 묶음"이 아니라 "조절 가능한 세계 생성기"로 바꾸는 것이 핵심.
두 논문 모두 "모든 도메인 우위"를 주장하지 않는다. 각 논문이 타겟한 도메인(자연 장면 / 실내 장면)에서 기존 합성 데이터가 약했던 부분을 절차적 생성으로 보완할 수 있음을 보인 것이다.

우리 연구로의 피벗: 기하 다양성만으로는 광학 다양성이 되지 않는다

Infinigen 시리즈는 무엇이 어디에 있는가를 다양하게 만든다. OpticalNav는 여기에 센서가 무엇을 어떻게 관측하는가를 붙이는 문제다.
필요 계층Infinigen 시리즈가 주는 것OpticalNav에서 추가해야 할 것
실내 구조 방, 복도, 문, 창문, 계단, 가구 배치 유리문/투명 파티션 중심 시나리오 선별
정답 기하 실제 메쉬 기반 depth, normal, segmentation 유리 경계, 위험 영역, 주행 가능 영역의 과업 정답
재질 RGB 렌더링 중심 procedural shader 편광·NIR 응답이 있는 BRDF / Mueller 재질 계층
관측 일반 RGB 렌더링과 표준 annotation Stokes, DoLP, AoLP, NIR, 센서 노이즈와 보정
로봇 과업 실시간 시뮬레이터 export 가능성 Isaac Sim 상태 전개, 충돌, 회피 성공률, rollout 평가
Infinigen Indoors 실내 구조 + 자산 + 배치 제약 ↓ Optical material layer 유리 / 금속 / 세라믹 / 플라스틱의 편광·NIR 응답 ↓ Mitsuba 3 파장·편광 기반 광학 관측 ↓ Isaac Sim 로봇 상태 전개 + 충돌 + 안전 주행 평가
Infinigen Indoors가 무엇이 있는가를 만들었다면,
OpticalNav는 그것이 어떻게 보이는가를 만든다.

  • Infinigen-Sim: Procedural Generation of Articulated Simulation Assets Infinigen 계열이 정적 장면 생성에서 관절 물체와 로봇 시뮬레이터 자산 생성으로 확장되는 흐름을 보여준다.
  • Infinigen-Stereo / What Makes Good Synthetic Training Data for Zero-Shot Stereo Matching? 절차적 생성기를 "데이터 품질을 실험적으로 튜닝하는 장치"로 쓰는 후속 흐름. RGB-NIR/HDR/stereo 배경과도 맞는다.

2. 실내 장면 생성과 embodied AI 비교축

  • ProcTHOR 절차적으로 집을 생성해 embodied AI 학습 규모를 키운 대표 기준점. 다만 AI2-THOR의 기존 에셋 라이브러리를 활용한다는 점에서 Infinigen Indoors와 좋은 대비가 된다.
  • Holodeck 언어 지시로 실내 환경을 생성하는 흐름. LLM이 상식적 방 구성과 물체 관계를 만들고, Objaverse 같은 대규모 에셋을 활용한다는 점에서 "완전 절차적 생성"과 비교하기 좋다.
  • BlenderProc Blender 기반 합성 데이터 생성 파이프라인의 실용 기준점. Infinigen을 "생성기"로, BlenderProc을 "데이터 생성 파이프라인"으로 놓고 비교하면 구조가 선명해진다.
  • Hypersim 전문가 제작 실내 장면 기반의 고품질 photorealistic synthetic dataset. Infinigen Indoors가 왜 "정적 에셋 의존"을 넘으려 했는지 설명할 때 대비 자료로 좋다.
  • Kubric 합성 영상과 깊이, 광학 흐름, 분할 정답을 만드는 범용 생성 도구. Infinigen의 "정답 추출" 장점과 나란히 읽기 좋다.

3. 로봇 navigation 쪽으로 이어 읽기

  • R2R / Matterport3D Simulator VLN의 기본 문제 설정. 실제 이미지 기반 환경이 왜 synthetic 환경의 visual richness 문제를 지적했는지 읽어두면, Infinigen의 "절차적 다양성" 가치가 더 잘 보인다.
  • VLN-CE R2R식 이산 graph navigation을 연속 환경으로 확장한 기준점. synthetic navigation dataset의 episode 형식, instruction, action interface를 설계할 때 직접 도움이 된다.
  • Habitat / HM3D 대규모 실내 3D scan 기반 embodied AI 생태계. Infinigen Indoors와 비교하면 "실제 스캔 기반 다양성"과 "절차적 생성 기반 제어 가능성"의 차이가 보인다.

4. OpticalNav로 이어지는 광학 렌더링 자료

  • Mitsuba 3 Polarization 문서 Stokes 벡터와 Mueller 행렬 기반 편광 렌더링을 구현 관점에서 설명한다. Infinigen 장면에 편광/NIR 관측을 붙일 때 핵심 자료.
  • Mitsuba 3 variant / spectral & polarization 문서 RGB, spectral, polarized variant의 차이를 확인할 수 있다. 장면 생성기와 광학 관측기를 분리해야 하는 이유를 설명하기 좋다.
  • pbrt v4 물리 기반 렌더링의 교과서이자 구현 레퍼런스. BRDF, spectral rendering, participating media, path tracing 개념을 정리하는 데 안정적이다.
  • Isaac Sim Infinigen SDG tutorial Infinigen 장면을 Isaac Sim의 synthetic data generation 파이프라인과 연결하는 실무 자료. RGB-first 데이터셋 구축과 잘 맞는다.

보고서 말미 요약 문단

Infinigen 시리즈는 합성 데이터를 "정적 에셋을 모아 만든 이미지 묶음"에서 "조절 가능한 세계 생성기"로 바꾼 연구 흐름으로 읽을 수 있다. 2023년 Infinigen은 자연 세계의 형상·재질·장면 구성을 생성 규칙으로 만들었고, 2024년 Infinigen Indoors는 이 철학을 실내 인공물과 배치 상식으로 확장했다. 이 흐름은 로봇 연구에서 특히 중요하다. 로봇 학습에는 단순히 예쁜 장면보다, 기하 정답과 장면 메타데이터가 있고, 필요한 실패 조건을 반복적으로 만들 수 있는 세계 생성기가 필요하기 때문이다. 다만 이 시리즈가 해결한 것은 주로 기하와 배치의 다양성이다. 유리문, 반사 표면, 편광·NIR 관측처럼 센서가 보는 방식 자체가 달라지는 문제는 별도의 광학 재질 계층과 물리 기반 렌더링이 필요하며, 이 지점이 OpticalNav 연구가 이어받을 수 있는 빈 공간이다.
