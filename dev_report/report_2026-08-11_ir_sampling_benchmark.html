rgb_max alone must not select the benchmark cohort. vp_000025__h_345 has a deceptively high RGB max of 0.567754, yet its mean/p95 are only 0.0132835 / 0.0239392; it is a mostly dark frame with a small highlight. The normalized cohort should require robust luminance mean and p95, not max.

Candidate policy to decide after visual review: run a 32-SPP RGB-passive preflight on every frame, then exclude a frame from the expensive IR sweep when both luminance p95 < 0.02 and mean < 0.01. This changes neither scene lighting nor SPP; it only stops investing in views that are already demonstrably non-informative. Thresholds remain a proposal here, not an enabled default.

Added apps/benchmark_ir_sampling.py. It refuses to start while a production worker occupies the selected GPU, then records each profile's synchronized mi_render_s mean/median/p95 plus device SM-active seconds, peak VRAM and energy estimate. The first view warms the scene/JIT and is excluded from aggregation.

python3 apps/benchmark_ir_sampling.py \
  --scene-dir out/ir_dataset/kitchen_structural_specular_lod/ir_effective_scene \
  --out out/ir_dataset/kitchen_structural_specular_lod/benchmarks/normalized_bright_cohort \
  --gpu-index <idle GPU> --warmup-count 1 \
  --viewpoints vp_000051@165,vp_000044@135,vp_000046@165,vp_000054@075,vp_000011@090,vp_000047@300 \
  --profile baseline:684x512:4000:4000:4000:8 \
  --profile fullres_reduced:684x512:1000:750:384:8 \
  --profile fast:512x384:768:512:256:6

Do not add --allow-shared-gpu for a decision-quality result: that mode deliberately labels device telemetry as non-attributable. The resulting benchmark_summary.json is the source for a cohort-normalized report.

Interpretation

  • Full-resolution pass-specific SPP is the cleanest first candidate: it preserves camera sampling, texture cap, resolution and depth while cutting requested sample work by about 82%.
  • Fast resolution/depth is an upper speed-bound rather than a default; its error images reveal the combined effect of lower SPP and lower spatial resolution.
  • The dark-view comparisons have intentionally poor PSNR against the 4000-SPP reference. That is evidence for the illumination gate, not evidence that 4000 SPP should be retained for dark views.
  • RGB/NIR ambient cannot currently be fused in one render because the band carrier is a whole-scene BSDF-weight swap. Flash-direct is additionally a different integrator/emitter pass. Therefore this report only evaluates safe sampling/depth/resolution controls.
