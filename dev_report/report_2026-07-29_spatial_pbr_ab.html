2. 실험 설계

  • A/B 쌍마다 geometry(GLB materialized OBJ part), UV, camera_to_world, light_to_world, spp, seed가 동일함을 assert_scene_pair_invariants로 강제한다. 차이는 material layer 하나뿐이다.
  • ROI는 별도 UV AOV 렌더에서 만든 object / metal / dielectric 마스크로 분리한다. 표의 값은 object ROI다.
  • positive = 실제 spatial metallic을 가진 4종. negative = metallic이 사실상 0인 불투명 dielectric control 3종 — 여기서 A와 B가 크게 다르면 그건 개선이 아니라 회귀 신호다.
  • 원 config는 유리 1종도 negative에 넣었지만, 이 리포트는 glass를 별도 role로 분리한다. §5에서 보듯 branch B에는 투과 경로 자체가 없어서 "변하지 않아야 정상"이라는 negative control의 전제가 유리에는 성립하지 않는다.

3.2 metallic이 정말 공간 변화하는가

robust_range ≥ 0.30만으로는 순수 0/1 마스크도 통과한다. polar texture 검증에는 중간값과 공간 구조가 함께 있어야 하므로 두 지표를 추가했다 — graded fraction(커버 텍셀 중 0.10 < m < 0.90 비율)과 gradient(커버 영역 평균 |∇m|). 이 기준으로 MonitorFactory와 ToiletFactory는 graded 0.1%(통짜 이진 blob)로 탈락했다.

한계: Infinigen에는 재질 내부의 metallic 그라디언트가 없다. Infinigen은 metallic을 재질 정체성(상수)으로, roughness/albedo를 표면 디테일(공간변화)로 설계한다. 따라서 여기서 얻을 수 있는 공간 변화는 하나의 UV atlas에 여러 재질이 패킹된 세그먼테이션이지 연속적인 물성 변화가 아니다. §6의 conductor index 결과와 같은 곳을 가리킨다 — spatial layer가 주는 것은 어디가 금속인가이지 얼마나·어떤 금속인가가 아니다.

5. glass baseline 수정과 그것이 드러낸 것

수정 전 glass A/B는 무효였다. branch A가 유리에 roughdielectric을 썼는데, 이 빌드에서 roughdielectric은 DoLP=0을 낸다 (dev_report 2026-07-06 §2.1). baseline에 편광이 아예 없었으므로 AoLP 거리가 정확히 0.0000으로 찍혔다 — 개선이 아니라 각도가 정의되지 않았던 것이다.

spatial_pbr_ab.py의 analytic glass 분기를 smooth dielectric으로 바꾸고 해당 4쌍을 재렌더했다. 프로덕션 경로(render_daemon.py:949)는 이미 smooth dielectric을 강제하고 있었으므로, 이 수정은 실험 하네스를 프로덕션 계약에 맞춘 것이다.

9. 판정과 한계

  • 판정: 감사된 입력에서 효과는 실재하지만 작다. positive ΔDoLP 0.0102 vs 불투명 dielectric control 0.0038 — 방향은 맞지만 분리비는 2.7배이고 절대값은 0.01 수준이다. 결함 입력으로 측정했던 이전 판의 14.4배는 재현되지 않는다(§3.1).
  • glass는 완전한 no-op이 됐다. per-slot optical_class 수정 + 투과 슬롯 우회 이후 PlantContainer의 ΔDoLP·AoLP 거리·RGB MAE가 모두 정확히 0이다. 수정이 의도대로 작동함을 확인해 준다.
  • 투과 재질에는 쓸 수 없다. §5 참조. branch B에 transmission BSDF 경로가 없어 유리가 불투명해진다. 프로덕션 배선의 선결 조건이다.
  • conductor 점유율 폭이 좁다. atlas의 커버 텍셀 기준 metal 비율은 14~82%로 골랐지만, 렌더에 들어가는 conductor_fraction(atlas 전체 평균)은 0.09~0.17에 그친다. UV 커버리지가 그만큼 낮기 때문이다. 더 넓은 폭이 필요하면 커버리지가 높은 자산을 따로 골라야 한다.
