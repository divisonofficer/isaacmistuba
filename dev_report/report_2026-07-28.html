2. optical perturbation 계약

용어는 mirror 없음/있음이 아니라 optical perturbation off/on으로 고정한다. base scene에도 기존 mirror asset이 존재하고, sidecar가 추가하는 geometry는 mirror wall 11개와 glass wall 1개다. edge polyline과 object line geometry를 다시 교차시킨 결과 disabled edge 7개는 모두 glass_auto_001에 귀속되며 mirror 귀속 edge는 0개다.

  • P1 rerouting: disabled edge 7개를 candidate에서 제거.
  • P2 collision stress: base candidate를 유지하고 해당 edge 선택 시 현재 node 유지 + glass collision 기록.
  • perturbed SPL denominator: disabled edge를 제거한 safe graph shortest path.
  • 동일 blocked edge 3회 연속 선택 시 실패 종료; max step은 min(50, max(20, 3×reference edges)).
해석 주의. 현재 geometry에서 edge-level collision cause는 glass뿐이다. mirror 효과는 collision count보다 decision flip, trajectory 변화와 off→on 성능 차이로 검정한다.

4. 구현된 실험 계약

  • Mixed training: train path마다 공식 4종 instruction을 epoch당 각 1회 노출. Legacy는 eval-only.
  • 모든 primary model은 batch 8, 40 epoch, 동일 optimizer update budget을 사용하고 validation SPL로 checkpoint 선택.
  • DUET는 ImageNet ViT-B/16 768-D, SkillNav/GR-DUET는 CLIP ViT-B/16 512-D native feature 유지.
  • 12개 수평 RGB만 입력한다. official 36-slot panorama의 horizon 12칸에만 feature를 채우고 미렌더 상·하 슬롯은 0으로 기록.
  • SkillNav Qwen router는 temperature 0/top-1, Vertical Movement expert는 pretrained frozen.
  • GR-DUET cold는 upstream reset 조건상 max_traj_num=1로 고정한다. 0은 첫 episode 뒤 reset되지 않으므로 cold 조건이 아니다.
  • GR-DUET adaptation은 train split만 사용한다. validation/test instruction마다 train node memory에서 graph를 새로 구성하고, 그 rollout에서 추가된 node는 다음 instruction 전에 폐기해 online update를 금지한다.
  • GR-DUET polar 입력은 S0, DoLP, cos(2AoLP), sin(2AoLP), valid mask로 변환.

prediction_trace.v1에는 candidate score, stop score, 선택 action, RGB/polar reference, collision/cause/revisit/goal distance와 모델별 선택 diagnostic을 저장한다. 400개 oracle/random smoke trace(20 episode × 5 instruction × 2 variant × 2 policy)를 생성해 schema write를 검증했다.

공식 DUET 1-update smoke (성능표 제외)

official loader에 8 train path × 공식 instruction 4종 = 32 sample을 넣고, 4 validation path × 5 instruction = 20 sample로 rollout했다. MatterSim action candidate, 36-slot HDF5 feature, forward/backward, AdamW update, validation rollout과 checkpoint 저장이 모두 통과했다. random initialization 1 update의 진단값은 SR 0, SPL 0, nDTW 30.15이며 모델 성능 추정치가 아니다. 상세 기록은 runs/model_smoke/duet_seed_20260728/smoke_manifest.json과 logs/train.txt에 남겼다.

이 과정에서 official connectivity pose의 floor 좌표를 잘못 교환하던 adapter 오류를 발견해 OpticalNav와 MatterSim 공통 좌표계인 (x, y, z)로 수정했다. 수정 전에는 실제 graph 이웃이 수직 이동처럼 해석되어 candidate에서 사라졌고, 수정 후 MatterSim 후보 노출과 회귀 테스트가 통과했다.

공식 GR-DUET adapter smoke (성능표 제외)

CLIP 512-D feature에서 113-node pano_inputs.h5와 candidate-angle map을 생성했다. candidate map은 connectivity의 모든 인접 edge와 불일치 0으로 검증했다. cold와 scene-adapted 모두 1 optimizer update, validation rollout과 SPL checkpoint-selection 경로를 통과했다. scene-adapted smoke는 train-only frozen memory를 각 validation instruction마다 재구성하며, validation에서 새로 방문한 node가 다음 instruction으로 전달되지 않음을 계약으로 기록한다. 이 smoke 역시 random initialization 진단이므로 성능표에서는 제외한다.

5. 평가 결과물

공통 evaluator는 SR, SPL, NE, OSR, nDTW, SDTW, Stop Accuracy와 4-way Robust Success/Worst-option SPL/Outcome Agreement/Instruction Sensitivity/Trajectory Agreement, off→on delta 및 collision 지표를 계산한다. paired bootstrap은 start-goal group resampling, 성공률은 exact McNemar, 연속 지표는 Wilcoxon, 다중 비교는 Holm correction을 적용한다.

동일 trace에서 graph/reference/prediction/perturbation/disabled edge/collision/divergence를 그린 PNG와 observation을 base64로 포함한 self-contained HTML replay를 생성하도록 구현했다. 관측 비교 anchor는 동일한 (VP, heading)의 base/perturbed frame만 사용한다. 출발 관측과 최초 decision/transition divergence 직전, 최초 optical collision 직전을 표시하며, 서로 다른 VP에 도착한 final state는 픽셀 비교에서 제외하고 별도 결과 패널로 보여준다. 실제 모델 trace가 생긴 뒤 success/failure/recovery 각 3개를 deterministic rule로 선택한다.

6. 현재 blocker와 실행 상태

데이터 blocker. polar archive에 base / vp_manual_0001 / h_330 / polar_cam / stokes_core_v1.npz가 없다. RGB와 off/on sensor index는 각각 1,356개로 정확히 대응하지만 Stokes는 2,711/2,712다. 원본 OpticalNav 및 bridge job에서도 해당 파일을 찾지 못했다. 존재하는 2,711개 NPZ의 full scan에서는 NaN/Inf 0, invalid mask 0으로 통과했다. sensor ablation 전에 이 한 view를 재렌더해 새 immutable export를 만들거나, 사전 등록된 missing-view 제외 규칙을 승인해야 한다.
  1. 완료: 격리 conda, MatterSim build/import, BERT annotation tokenization, split/connectivity runtime staging.
  2. 완료: ImageNet ViT-B/16 768-D와 CLIP ViT-B/16 512-D native HDF5 각각 339 key 생성.
  3. 완료: DUET 1-update official-code smoke. 비교 성능에는 미포함.
  4. 완료: GR-DUET cold/scene-adapted 1-update smoke와 train-only frozen-memory validation.
  5. 진행 중: GR-DUET/DUET/SkillNav official checkpoint 다운로드. 공개 접근은 확인했으나 현재 외부 전송이 병목.
  6. checkpoint 확보 후 3 seeds의 DUET·SkillNav·GR-DUET cold/adapted를 동일 update budget으로 학습.
  7. validation SPL checkpoint 고정 후 test off/on P1/P2 및 GR-DUET sensor ablation 실행.
  8. 집계표·paired 통계·replay HTML/PNG 생성. 그 전까지 표의 모델 성능 칸은 “미실행”으로 유지.
  9. polar ablation 전 missing Stokes를 복구한 새 immutable export를 만들거나 사전 등록 제외 규칙을 승인.
