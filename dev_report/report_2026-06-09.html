Daily Development Report · 2026-06-09

작업트리 변경 내용을 추적해 보니, 에디터는 분해되고 렌더 파이프라인은 XML-native / job push / partial export 쪽으로 이동했다

현재 변경은 단일 기능 패치라기보다 OpticalNav dataset editor의 구조 전환이다. 파이프라인 변화

1. Authoring map save 시 canonical authoring map을 유지하고, 필요하면 render sync를 deferred 상태로 남긴다.
2. Sync sidecars render_scene.xml과 함께 materialization audit, xml_scene_index, render_readiness가 생성된다.
3. XML-native editor editor는 xml_scene_index의 mesh_path를 읽고 scene mesh_cache OBJ를 표시한다.
4. Render monitor graph_sweep, episode_nodes, preview_probe job이 batch panel과 WebSocket 상태로 합쳐진다.
5. Filtered export rendered episode만 dataset.json / splits에 등재하고 zip은 전체 파일을 보존한다.

묶음변경 내용의미

Export UI only_completed, current scene scope, explicit episode_ids를 보낼 수 있는 export service로 정리. partial sweep 결과만 dataset으로 내보낼 수 있다.

3D Editor 변경

기능변경 내용리스크
XML-native preview MapEditor3D가 xmlSceneIndex.shapes[].mesh_path를 보고 render-side OBJ를 표시한다. async OBJ load 후 reactive version bump로 placeholder를 실제 mesh로 교체한다. xml index stale 상태에서 editor mesh가 render_scene.xml과 어긋날 수 있어 stale warning이 필요하다.
Mesh cache objMeshCache.ts가 memory LRU + IndexedDB 캐시, 동시 fetch 제한, large mesh guard를 제공한다. 대형 OBJ는 placeholder 처리되므로 editor/렌더 시각 차이를 UI에 명시해야 한다.
Hot camera click-drag placement, preview pose history, active rig intrinsics 기반 frustum, result texture overlay를 지원한다. preview camera history를 더 명확한 editor object 모델로 승격하는 후속 작업이 남아 있다.
Frustum click filter visible object/parent만 raycast 대상으로 삼아 숨겨진 frustum plane이 클릭되는 문제를 줄인다. layer별 visibility와 pickability를 계속 같은 규칙으로 유지해야 한다.

Render Daemon 변경

영역변경 내용
Materialization audit render_scene_materialization.json에 OBJ/fallback/emitter/wall cube count, fallback reason, extracted material status breakdown을 기록한다.
XML scene index xml_scene_index.json에 shape_id, shape_type, mesh_path, bsdf_ref, transform, fallback/source_ref/material_id를 기록한다.
Scene mesh cache render XML의 OBJ filename을 scene별 mesh_cache로 staging하고 /mesh-cache/<filename> endpoint로 제공한다.
OBJ/MTL texture extraction MooreLane direct OBJ의 mtllib/map_Kd를 읽어 measured BSDF보다 source texture를 우선할 수 있는 경로가 들어갔다.
Sync status sync started/error/deferred/blocked 상태를 scene annotation metadata에 patch해서 save success와 async render readiness를 구분한다.
Job status push job status snapshot/cache invalidation/push subscriber 경로가 추가되어 frontend가 4초 polling 대신 WebSocket frame을 받을 수 있다.

Dataset export / validation

파일변경 내용효과
exporters/custom_json.py is_episode_complete(), episode_ids / scene_ids / only_completed filter, skipped count, scoped total을 추가. 부분 렌더 후 완성 episode만 dataset index와 split에 들어간다.
validation.py scene_ids scope를 받아 해당 scene의 annotation/graph/episode만 검증한다. 한 프로젝트에 여러 scene이 있을 때 다른 scene의 stale 상태가 현재 export를 막지 않는다.
sensor_sweep.py custom position에서 node_id, heading_id, request_id, render_mode, preview_id를 payload에서 보존한다. hot camera preview job이 batch/job panel에서 안정적으로 추적된다.
test_viewpoint_graph.py custom preview metadata 보존 단위 테스트를 추가. preview_probe 계약을 navigation_dataset 레벨에서 고정한다.
