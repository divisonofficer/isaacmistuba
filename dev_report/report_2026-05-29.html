뷰 프러스텀 Mitsuba 렌더 프리뷰
MapEditor3D · updateFrustums() · observationScan → Three.js 텍스처 플레인
핵심 성과: Mitsuba로 렌더된 뷰포인트 이미지가 3D 공간에 실시간으로 표시된다. 각 노드에서 카메라 방향으로 와이어프레임 프러스텀이 펼쳐지고, 그 안에 실제 렌더 RGB 이미지가 텍스처로 입혀진다. 385개 오브젝트·3개 리전·3개 유리·300개 노드 씬 기준.
뷰 스트럼을 이용해서 미츠바 렌더된거 보여주는 뷰 — Sensor 모드 · 300 노드(주황 점) + 하늘색 와이어프레임 프러스텀 + 실제 Mitsuba RGB 텍스처. 바닥 완료 링: 초록(전 방향 렌더 완료) / 주황(부분 완료) / 회색(미렌더). 385obj · 3reg · 3glass · 300nodes.

Before (O(n²) 이중 루프)

for oy, ox in obstacle_cells:          # O(m)
    for dy in range(-r, r+1):          # O(r)
        for dx in range(-r, r+1):      # O(r)
            if dx*dx+dy*dy > r*r:
                continue
            traversable[oy+dy, ox+dx] = False
# 총 O(m × r²) — r=5(0.5m/0.1m), m=장애물 수
