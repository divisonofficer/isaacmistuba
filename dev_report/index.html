핵심 원칙: robomituba_bridge는 Isaac Sim과 Mitsuba 어느 쪽에도 의존하지 않는 순수 Python 계약 계층입니다. 모든 경로는 repo-relative로 저장되어 어디서나 이동 가능합니다.

이 프로젝트는 NVIDIA Isaac Sim에서 생성한 로봇 씬을 Mitsuba 3 물리 기반 렌더러로 렌더링하여 RGB, Depth, Normal, Polarization 등 다양한 모달리티의 고품질 센서 데이터를 생성합니다. 생성된 데이터는 로봇 학습(ML/Vision)에 활용됩니다.

전체 시스템은 3개의 독립 계층으로 분리되어 있어, Isaac Sim 없이도 렌더링이 가능하고 Blender 등 다른 USD 작성 도구에서도 동일한 bridge를 활용할 수 있습니다.

Job Lifecycle

1
Job ID 생성
make_job_id() → job-20260522T120000z-abc123
2
디렉터리 레이아웃 생성
ensure_job_layout(repo_root, job_id) → out/bridge_jobs/job-.../ snapshot/ usd/ renders/ logs/
3
씬 스냅샷 추출
Isaac Sim 또는 USD에서 SceneSnapshot 생성 (meshes, materials, cameras, lights, poses)
4
매니페스트 생성 + 번들 저장
create_job_manifest() + write_job_bundle() → manifest.json scene.json materials.json cameras.json lights.json
5
렌더링
load_job_bundle(manifest_path) → Mitsuba 렌더링 → EXR 저장
6
결과 번들 저장
write_observation_bundle_manifest() → observation_bundle.json

워커 스레드 구조

WorkerProcess
├── Thread: writer   → outbound queue → stdin (JSONL)
├── Thread: reader   → stdout (JSONL) → event dispatcher
└── Thread: watchdog → heartbeat 모니터 (timeout: 30s)
                       → kill + restart on timeout
                       → cooldown: 30s
                       → 5분 내 3회 비정상 종료 → degraded

충돌 정책

# 워커 종료 시 in-flight 작업 처리
# 실행 중 작업: reason='worker_exited' 로 failed 처리
# 대기 중 작업: reason='worker_restarting' 로 failed 처리
HEARTBEAT_TIMEOUT_S  = 30.0
RESTART_COOLDOWN_S   = 30.0
DEGRADED_WINDOW_S    = 300   # 5분
DEGRADED_MAX_EXITS   = 3

Data Flow
Isaac Sim → 렌더링 출력 전체 흐름
①
Isaac Sim 씬 작성
USD 씬 생성 (geometry, materials, lights), 카메라 배치, 로봇 배치. Isaac extension 또는 standalone 스크립트로 내보내기.
②
SceneSnapshot 추출
usd_snapshot.extract_snapshot_from_usd() → meshes + OBJ files materials.json cameras.json lights.json
③
Job Bundle 저장
write_job_bundle(layout, manifest, snapshot) → out/bridge_jobs/job-.../manifest.json snapshot/scene.json
④
Render Daemon에 요청
HTTP POST → RenderRequest (JSON) → WorkerManager.submit() → JSONL to worker subprocess
⑤
Mitsuba 씬 빌드
load_job_bundle() → MitsubaSceneBuilder.build_snapshot() → mi.load_dict(scene_dict)
⑥
멀티모달 렌더링
render_modalities(scene_dict, modalities, config) → Pass 1: RGB (4096 spp) | Pass 2: AOV (16 spp) | Pass 3: Polarization (256 spp)
⑦
결과 저장
renders/camera_0/rgb.exr depth.exr normal.exr albedo.exr polar_*.exr observation_bundle.json
