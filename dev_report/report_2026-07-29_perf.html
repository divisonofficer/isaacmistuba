4 · NIR albedo 합성 — class→ρ₈₅₄ prior + spatial transfer, 1채널

왜 RGB에서 NIR을 만들 수 없나. Infinigen 자산의 base_color는 가시광 RGB 3-point(R·G·B 세 표본)뿐이다. 근적외선 반사율은 물리적으로 독립인 4번째 채널이라 RGB로부터 함수적으로 복원할 수 없다 — 예: 초록 잎과 초록 페인트는 RGB에서 동일해 보이지만, 잎은 red-edge 때문에 NIR에서 밝고(ρ₈₅₄≈0.5) 페인트는 어둡다. 따라서 NIR = f(RGB)는 원천적으로 틀린 접근이다.

3-tier 우선순위 (측정 → 라이브러리 → class prior)

① measured자산에 실측 NIR이 있으면 사용 (현재 거의 없음)
→
② library동일 재질군의 공개 분광 라이브러리
→
③ class prior ★ 구현physical class → ρ₈₅₄ 평균+분산 prior

물리-재질 분류: physical_material_for(shader, optical_class) → 18개 클래스 중 하나 (+confidence). 반사율 조회: nir_reflectance(pmat, band) → μ_c, spread. configs/datasets/class_band_reflectance_v1.json.

spatial transfer — 절대 레벨은 물리, 공간 구조만 RGB에서

ρNIR(x) = clip[ μc · ( 1 + αc · ( L(x) / median(L) − 1 ) ), 0, 0.95 ]
μc = class NIR 평균 반사율(위 표) — 절대 밝기를 결정.   L(x) = 픽셀의 가시광 luminance(구조/디테일).   αc = rgb_structure_weight — RGB의 상대 밝기 패턴(구조)만 얼마나 반영할지. 색(hue)은 쓰지 않는다. 즉 나뭇결·얼룩 같은 공간 텍스처는 RGB에서 빌려오되, 그 위의 NIR 절대 반사율은 물리 클래스가 못박는다. synthesize_nir_texture(rgb_albedo_linear, pmat, band).

metal·glass 예외 + 1채널 렌더

금속·유리는 diffuse 반사율을 부여하지 않는다. nir_scalar_reflectance()가 metal/glass에 None을 반환 → 가짜 diffuse ρ를 씌우지 않고 Fresnel(dielectric / roughconductor) 경로로 처리(편광과 일관). NIR band는 discrete-band 씬에서 단일밴드 스펙트럼으로 blendbsdf weight-flip 렌더되며, S0는 3채널 RGB가 아니라 1채널 반사율 맵이다 — polar-LOD 리포트에서 선인장 몸통(0.52)/흙(0.30)이 물성별로 다른 명도의 단일채널로 렌더됨을 검증.
