4. 근본원인 — glTF metallicFactor를 무시

glTF metallic-roughness는 texture 하나로 끝나지 않는다. 최종 metallic은 다음 곱이다.

effective_metallic(u,v) = metallicRoughnessTexture.B(u,v) × metallicFactor

이번 GLB는 roughness texture를 pack하기 위해 B 채널을 1.0으로 채우고, material의 metallicFactor=0으로 diffuse를 표현한다. 원본 스크립트는 B만 저장하므로 1.0×0을 1.0으로 잘못 해석한다.

즉시 수정 조건: baseColor/roughness/metallic texture를 추출할 때 glTF factor를 반드시 곱해야 한다. 특히 roughnessFactor와 baseColorFactor도 같은 원칙으로 처리해야 한다.

5. factor만 고쳐도 부족 — optical_class가 우선

Infinigen은 이름이 shader_hammered_metal이어도 Principled metallic 값이 0인 사례가 있다. 따라서 factor를 올바르게 적용하면 false metal은 사라지지만, 실제 metal material part까지 plastic으로 놓칠 수 있다.

Glass 예외 해석: 현재 mixed PlantContainer GLB에는 sand/plant part용 atlas가 존재한다. “오브젝트에 atlas가 있다”가 glass가 textured plastic이 되어야 한다는 뜻은 아니다. GLB material part를 분리하고 glass slot에 analytic dielectric를 유지하는 것이 정답이다.

8. Robomituba texture-only converter 구현

mitsuba_converter.spatial_pbr와 manifest CLI apps/convert_spatial_pbr_textures.py를 추가했다. geometry, UV, transform은 건드리지 않고 이미 bake된 atlas만 Mitsuba용 공간 가변 BSDF 입력으로 바꾼다.

baked basecolor ───────────────────────────────→ basecolor.png baked roughness × roughnessFactor ── square(r) ─→ alpha.png baked metallic × metallicFactor ────────────────→ metallic.png / bsdf_weight.png linear basecolor + metallic texel ── F0 match ──→ conductor_index.png / eta·k maps manifest + factors + preset provenance ─────────→ spatial_pbr.json
  • 새 pbr.channels와 기존 baked_* manifest 계약을 모두 읽는다.
  • glTF channel/factor를 적용하고, roughness는 alpha=r²로 변환한다.
  • metallic을 blur하거나 이진화하지 않고 continuous blendbsdf weight로 보존한다. threshold는 conductor preset 선택에만 사용한다.
  • preset 후보는 실제 conductor 7종(Ag, Al, Au, Cr, Cu, Ni, W)으로 제한하고 모든 선택 근거를 sidecar에 기록한다.

양성 4종의 평균 nearest-F0 오차는 각각 0.8555, 0.6338, 0.8407, 0.6478로 높았고 대부분 W로 몰렸다. 즉 spatial metallic bake와 blend weight는 신뢰할 수 있지만, basecolor만으로 실제 금속 종류와 spectral n/k를 확정할 수는 없다. material optical_class/이름 기반 preset을 우선하고 F0 match는 confidence gate를 통과한 경우에만 보조값으로 써야 한다.

10. 다음 구현 순서

  1. material builder에 converter sidecar를 연결하되 glass → explicit metal → texture blend → diffuse 우선순위를 보존한다.
  2. nearest-F0 오차 threshold와 semantic fallback을 추가해 confidence가 낮은 n/k 자동 배정을 차단한다.
  3. 구현·smoke 실행 완료: 양성 4종·음성 4종을 GLB UV/normal parts로 staging하고, cuda_ad_spectral RGB A/B와 cuda_ad_spectral_polarized A/B를 독립 생성하는 harness/config를 추가했다. 256²/64 spp에서 32/32 pair·128/128 render를 완료했고 pair별 RGB/polar montage와 mode별 metrics를 저장했다.
  4. Phase 2 indexed_roughconductor에서 conductor index로 full eta(λ), k(λ)를 선택한다.
  5. 양성 4종·음성 4종과 synthetic Au/Cu/Al/plastic atlas를 regression fixture로 고정한다.

14. Stage 2 전 필수 수정

  1. nested Principled-to-Emission helper를 Base Color, Roughness, Metallic 공통 경로로 일반화한다.
  2. unit별 UV coverage mask를 별도로 bake하거나 생성해 padding을 제외한 texel만 검사한다.
  3. 네 채널 모두에 bake_validation을 기록한다: covered sample 수, robust percentile range, black/constant/spatial 결과, threshold.
  4. strict mode에서 linked channel의 covered sample 0, all-black, robust constant를 실패시킨다.
  5. constant는 원래 socket이 unlinked였을 때만 허용한다. normal N/A는 verified-flat 또는 no-material일 때만 허용한다.
  6. Stage 1만 다시 실행하고 linked-collapse 0을 확인한 뒤 Stage 2를 연다.
현재 promotion 판정 정정: GLB/UV/normal recovery는 성공했지만 non-normal spatial PBR acceptance는 실패다. 현재 설치된 v2 manifest를 Stage 2에 사용하거나 sync/RGB/polarization render를 시작하면 안 된다.

  • 회귀 테스트는 GLB/PBR 관련 9 passed이며, black linked texture 거부 테스트를 포함한다. Mitsuba conda 프로세스는 종료 시 exit 139를 냈지만 pytest 자체는 9개 모두 통과했고 별도 py_compile/diff check도 통과했다.
  • strict positive probe: Balloon 1개는 64²에서 albedo robust range 0.336, roughness 0.514, normal spatial로 export/manifest validation 통과했다. strict negative probe: Blanket은 albedo/roughness가 black으로 판정되어 export가 중단됐다.

23. ARMN file completeness와 source semantics의 분리

visible mesh마다 albedo/roughness/metallic/normal 네 파일을 생성할 수 있다는 것과, 원본 재질이 네 개의 독립적인 spatially varying PBR channel을 보유했다는 것은 다른 주장이다. UV를 만들고 강제 bake하면 상수값도 PNG가 되며, Blender의 NORMAL bake는 source normal texture가 없어도 evaluated surface normal을 tangent-space atlas로 합성한다.
