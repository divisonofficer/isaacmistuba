      {# 방식 선택 카드 #}
      

        

          
🚀 A. Runtime — .bat launcherA. 런타임 — .bat 런처

          
Run the .bat from the repo once. No installation step. Best for quick testing.repo의 .bat을 한 번 실행합니다. 설치 단계 없음. 빠른 테스트에 적합합니다.

        

        

          
📦 B. Permanent — extsUser registrationB. 영구 등록 — extsUser

          
Copy the extension folder to extsUser. Isaac auto-discovers it on every launch. Best for regular use.extension 폴더를 extsUser에 복사합니다. Isaac이 실행마다 자동으로 인식합니다. 정기 사용에 적합합니다.
