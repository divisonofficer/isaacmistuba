# navigation_dataset

OpticalNav-v0.1 dataset-authoring layer for Robomituba.

This package adds custom JSON episode contracts, scene annotations,
top-down traversability grids, A* planning, simple instruction templates,
dataset export, and basic evaluator utilities. It intentionally keeps
training, full physics rollout, LiDAR-like output, and benchmark-native
export formats out of v0.1.
